# PROXI

Personal AI Security & Authority Infrastructure. PROXI includes a local FastAPI enforcement service and a Next.js owner dashboard for managing agents, sessions, policies, and approvals and inspecting trust, audit, and integration status. It is not a hosted deployment.

Start each development session with the [mandatory handoff workflow](docs/DEVELOPMENT.md#session-workflow). See [Development](docs/DEVELOPMENT.md) for local run and test commands, [Architecture](docs/ARCHITECTURE.md) for boundaries, and [Current status](logbook/CURRENT_STATUS.md) for project progress and the recommended next prompt.
